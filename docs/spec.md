# 1. 개요와 공통 기준

Uni-Form은 대학(원)생이 설문을 만들고 서로 응답하는 플랫폼이다.
MVP에서는 응답 동기를 포인트 대신 **주간 응답 횟수 리더보드**로 만든다.
AI 모델·API·데이터베이스의 구체적인 구성은 개발자가 결정한다.

## 1.4 마감 시각

한국 시간 마감일 23:59까지 응답 시작과 제출을 허용하고 다음 날 00:00부터
차단한다. 예를 들어 9월 20일 마감 설문은 9월 21일 00:00 직전까지 서버에
도착한 제출만 받는다. 응답 시작 시각이 아니라 제출 요청이 서버에 도착한
시각으로 판단한다. 직접 마감은 마감 요청이 서버에 도착한 시각을 마감
시각으로 기록한다(8.3). 목표 인원을 채워도 마감 시각은 바뀌지 않는다.

# 2. 회원가입·로그인

## 2.1 가입 방식과 동의

  -----------------------------------------------------------------------
  **항목**           **기준**
  ------------------ ----------------------------------------------------
  가입 방식          이메일과 비밀번호로 가입하고 인증 링크로 이메일을
                     확인한다. 소셜 로그인(카카오, 네이버)과 인증번호
                     방식은 쓰지 않는다.

  대학 인증          학교 이메일·학번·재학증명서 인증은 없다. 프로필은
                     자기보고 정보이며 \"인증된 재학생\"처럼 표시하지
                     않는다.

  대상               대학(원)생 대상으로 안내하되 가입은 막지 않는다.
                     해당하지 않으면 프로필에서 \"해당 없음\"을 고른다.

  가입 연령          만 14세 이상만 가입한다. 필수 체크로 확인한다.

  필수 동의          서비스 이용약관(금지 설문 내용과 운영 삭제, 리더보드
                     운영·보상·동점 추첨 규칙, 재가입 제한 포함),
                     개인정보 수집·이용(수집 항목과 목적, 보관 기간,
                     파기, 보상 발송을 위한 이메일 이용, 탈퇴 이메일 해시
                     보관 포함), 만 14세 이상 확인

  선택 동의          마케팅 정보 수신. 동의하지 않아도 모든 기능을 쓸 수
                     있고 마이페이지에서 바꿀 수 있다.
  -----------------------------------------------------------------------

동의 시각과 약관 버전을 저장한다. 약관이 바뀌면 다음 로그인 때 바뀐 필수
항목에 다시 동의를 받는다.

## 2.2 가입 순서와 계정 상태

  -----------------------------------------------------------------------
  **순서**           **처리 내용**
  ------------------ ----------------------------------------------------
  1\. 정보 입력      약관 동의 후 이메일, 비밀번호(8자 이상, 영문·숫자
                     포함), 닉네임, 프로필(2.3)을 한 화면에서 입력한다.

  2\. 서버 확인      이메일 형식, 이미 가입된 주소, 탈퇴 후 30일 이내
                     주소(2.5), 닉네임 규칙과 중복, 프로필 필수 선택을
                     확인한다. 걸리면 이유를 안내하고 입력값을 유지한 채
                     멈춘다.

  3\. 인증 링크      계정을 \"인증 대기\"로 만들고 링크를 보낸다.
                     유효기간과 재발송 간격은 인증 서비스 기본값을
                     따르며, 미수신·만료 시 재발송을 제공한다. 닉네임은
                     이 시점에 선점된다.

  4\. 링크 확인      계정을 \"활성\"으로 바꾸고 전체 설문 목록으로
                     보낸다. 가입 보너스는 없다.
  -----------------------------------------------------------------------

  -----------------------------------------------------------------------
  **계정 상태**      **뜻과 허용 동작**
  ------------------ ----------------------------------------------------
  인증 대기          링크를 누르지 않은 상태. 재발송과 가입 이메일 변경만
                     가능하다. 7일 동안 인증하지 않으면 가입 정보를
                     지우고 닉네임 선점을 해제한다.

  활성               모든 기능을 쓸 수 있다.

  이용 제한          운영자가 정책 위반을 확인해 제한한 상태(10.3).
                     로그인, 사유 확인, 마이페이지 조회만 가능하고
                     게시·응답·팀 작업은 막으며 리더보드에서 숨긴다.

  탈퇴               로그인할 수 없다. 2.5에 따라 처리한다.
  -----------------------------------------------------------------------

상태가 바뀔 때마다 시각과 사유를 기록한다.

## 2.3 닉네임과 프로필

  -----------------------------------------------------------------------
  **항목**           **기준**
  ------------------ ----------------------------------------------------
  닉네임             필수. 2\~12자, 한글·영문·숫자. 공백만 입력 불가.
                     다른 회원과 중복 불가(영문 대소문자 구분 없음).
                     리더보드와 팀 화면에 표시된다.

  성별               필수. 남성 / 여성 / 응답하지 않음

  학년               필수. 1학년 / 2학년 / 3학년 / 4학년 이상 / 대학원 /
                     해당 없음

  전공 계열          필수. 인문사회 / 상경 / 공학 / 자연과학 / 의약 /
                     예체능 / 교육 / 해당 없음

  재학 상태          필수. 재학 / 휴학 / 졸업 / 해당 없음
  -----------------------------------------------------------------------

프로필은 닉네임 외에는 목록에서 고른다. 자유 입력을 허용하면 같은 전공이
여러 값으로 저장되어 분류할 수 없다. MVP에서 프로필은 다른 회원에게
보여주지 않고, 설문 참여를 막는 데도 쓰지 않는다. 서비스 이용자 통계와
이후 교차 분석·모집 대상 기능을 위해 수집하며, 이 목적을 개인정보 동의에
적는다.

닉네임과 프로필은 마이페이지에서 언제든 바꿀 수 있고 변경 횟수·주기
제한은 없다. 리더보드에는 현재 닉네임을 표시한다. 바꾼 닉네임도 중복
검사를 한다. 변경 전후 값과 시각을 기록한다. 부적절한 닉네임은 자동
검사하지 않고, 운영자가 관리자 화면에서 임의 닉네임으로 바꾼다(10.3).

## 2.4 로그인과 비밀번호

  -----------------------------------------------------------------------
  **상황**           **처리**
  ------------------ ----------------------------------------------------
  로그인 실패        이메일과 비밀번호 중 무엇이 틀렸는지 구분하지 않고
                     같은 문구로 안내한다. 계정 잠금은 두지 않고 인증
                     서비스의 기본 요청 제한만 적용한다.

  비밀번호 재설정    가입 이메일로 재설정 링크를 보낸다. 가입되지 않은
                     주소여도 같은 안내 문구를 보여준다.

  비밀번호 변경      마이페이지에서 현재 비밀번호를 확인한 뒤 바꾼다.

  로그인 후 이동     인증 대기는 인증 안내, 이용 제한은 제한 사유와
                     고객센터 안내 화면으로 보낸다.
  -----------------------------------------------------------------------

## 2.5 탈퇴와 재가입

  -----------------------------------------------------------------------
  **항목**           **처리**
  ------------------ ----------------------------------------------------
  탈퇴 전 안내       아래 처리 내용을 안내하고 확인을 받는다. 팀장이면
                     팀장을 넘기라고 먼저 안내한다(3.4).

  본인 명의 모집 중  마감 처리한다. 결과는 더 볼 수 없고 7.4의 파기
  설문               일정을 따른다. 본인 명의 초안은 삭제한다.

  팀                 모든 팀에서 나간다. 팀 초안과 팀 설문은 팀에 남는다.
                     팀장이면 3.4에 따라 처리한다.

  리더보드           순위표에서 즉시 빠지고 점수는 복구하지 않는다. 진행
                     중이거나 발송 전인 시즌 보상 대상에서도 제외한다.

  제출한 응답        회원 연결을 끊고 익명화해 다른 설문 결과에 남긴다.
                     원문은 해당 설문의 파기 일정을 따른다.

  닉네임·프로필      삭제한다. 닉네임은 탈퇴 즉시 다른 회원이 쓸 수 있다.

  재가입             탈퇴일로부터 30일 동안 같은 이메일로 가입할 수
                     없다(점수 초기화·보상 중복 수령 방지). 이를 위해
                     탈퇴 이메일을 해시로 보관한다.

# 3. 팀

팀은 **설문을 함께 만들고, 게시한 설문의 현황과 결과를 함께 보는
묶음**이다. 팀장 포함 팀원 모두 같은 화면을 본다. 팀 단위 리더보드는
없다.

  인원               팀장 포함 최대 6명. 한 회원은 최대 3개 팀에 속할 수

  가입               팀장이 만든 초대 링크로만 가입한다. 팀장은 언제든

  **항목**           **기준**
  ------------------ ----------------------------------------------------
  팀 초안 만들기     새 설문을 만들 때 작성 공간으로 \"내 설문\" 또는
                     소속 팀을 고른다. 내 초안도 게시 전이면 팀 초안으로
                     옮길 수 있다(팀 초안을 개인으로 되돌리기는 불가).

  함께 수정          팀원 누구나 제목·설명·문항·보기·목표 인원·마감일을
                     수정하고 FormMate와 대화할 수 있다. FormMate 대화
                     기록은 팀원 모두 본다.

  편집 표시          초안마다 마지막 수정자 닉네임과 수정 시각을
                     보여준다. 다른 팀원이 초안을 열고 있으면 \"○○님이
                     편집 중\" 표시를 한다.

  충돌 처리          MVP는 실시간 동시 편집(글자 단위 동기화)을 필수로
                     하지 않는다. 저장할 때 다른 팀원이 먼저 저장한
                     내용이 있으면 덮어쓰지 않고, 최신 내용을 불러온 뒤
                     내 변경을 다시 적용하도록 안내한다. 내 변경 내용은
                     사라지지 않게 화면에 남긴다.

  기록               누가 언제 어떤 문항을 추가·수정·삭제했는지 변경
                     기록을 남긴다. 되돌리기는 4.2의 AI 변경 되돌리기와
                     같은 방식을 쓴다.
  -----------------------------------------------------------------------

## 3.3 팀 설문

팀 초안을 게시하면 팀 설문이 되고, 목록에는 팀 이름으로 표시한다. 팀
설문의 현황과 결과 요약은 게시 시점과 관계없이 현재 팀원 모두 볼 수
있다.

팀원은 자기 팀의 팀 설문에 응답할 수 없다. 리더보드 점수를 팀 안에서
몰아주는 것을 막기 위함이다. 설문 게시 후 팀에 들어온 회원도 같으며,
가입 전에 이미 제출한 응답은 그대로 둔다. 팀원이 본인 명의로 게시한
설문은 이 제한을 받지 않는다.

## 3.4 나가기·내보내기·해산

  -----------------------------------------------------------------------
  **상황**           **처리**
  ------------------ ----------------------------------------------------
  팀원 나가기 /      그 팀의 팀 초안과 팀 설문 결과에 더 접근할 수 없다.
  내보내기           작성한 내용은 팀에 남는다. 이후 그 팀의 팀 설문에
                     응답할 수 있다.

  팀장 나가기        팀장을 다른 팀원에게 넘긴 뒤에만 나갈 수 있다.

  팀장 탈퇴          팀장을 넘기지 않았다면 가장 먼저 가입한 팀원에게
                     자동으로 넘긴다. 남은 팀원이 없으면 해산한다.

  해산               팀장만 할 수 있다. 팀 초안은 해산 당시 팀장의 개인
                     초안으로 옮긴다. 모집 중인 팀 설문은 마감 시각까지
                     유지하고, 관리 권한과 결과 조회는 해산 당시 팀장에게
                     남는다.
  -----------------------------------------------------------------------

# 4. 설문 제작

## 4.1 설문 만들기와 저장

  -----------------------------------------------------------------------
  **기능**           **동작**
  ------------------ ----------------------------------------------------
  새 설문 만들기     작성 공간(내 설문 / 팀)을 고른 뒤 FormMate와
                     대화해서 만들거나 직접 작성한다. AI가 만든 질문도
                     직접 고칠 수 있고, 직접 작성 중에도 AI 도움을 받을
                     수 있다.

  기존 설문 복사     본인 설문 또는 소속 팀 설문의
                     제목·설명·문항·보기·문항 설정을 복사해 같은 작성
                     공간에 새 초안을 만든다. 응답은 가져오지 않는다.

  AI 문항 추천 /     AI가 추가 질문이나 수정안(어려운 표현, 답을 유도하는
  질문 검토          질문, 한 문항에 두 가지를 묻는 질문 등)을 제안하고,
                     사용자가 고른 것만 반영한다.

  직접 수정·임시저장 질문 추가·수정·삭제·순서 변경이 가능하다.
                     미완성이어도 저장한다.

  게시 전 확인       완성한 설문을 시험 삼아 풀어볼 수 있다. 이 답은
                     집계하지 않고 리더보드 점수도 주지 않는다.
  -----------------------------------------------------------------------

개인 초안은 작성자만, 팀 초안은 현재 팀원만 조회·수정할 수 있다. 실제
저장에 성공한 경우에만 저장 완료로 처리한다. 순서를 바꿔도 같은 질문을
구분하도록 문항 번호와 내부 식별값을 따로 관리한다. \"3번 문항을
고쳐줘\"는 현재 세 번째 질문을 뜻한다.

## 4.2 FormMate와 대화하며 설문 만들기

FormMate는 자체 학습 모델 대신 외부 AI API를 사용하는 설문 제작
에이전트다.

  -----------------------------------------------------------------------
  **단계**           **동작**
  ------------------ ----------------------------------------------------
  1\. 주제 파악      조사 목적·대상·알고 싶은 내용·희망 응답 시간을
                     파악한다. 필요한 것만 하나씩 묻고 이미 답한 것은
                     다시 묻지 않는다.

  2\. 초안 만들기    정보가 충분하거나 사용자가 \"일단 만들어줘\"라고
                     하면 초안을 만든다. AI가 임의로 정한 내용은 무엇을
                     가정했는지 함께 설명한다.

  3\. 대화로 다듬기  문항 추가·표현 수정·보기 변경을 계속 요청할 수 있고,
                     사용자가 적용하기로 한 제안만 반영한다. 대화 횟수로
                     끊지 않는다.

  4\. 확인하고 게시  사용자가 직접 확인·수정한 뒤 게시한다. AI가
                     만들었다는 이유로 자동 게시하지 않는다.
  -----------------------------------------------------------------------

AI가 바꾼 내용은 다른 작성 내용을 지우지 않고 되돌릴 수 있어야 한다. AI
응답을 기다리는 동안 사용자나 다른 팀원이 직접 고쳤다면 이전 AI 결과로
덮어쓰지 않고 최신 내용으로 다시 요청하도록 안내한다. AI가 작동하지
않거나 형식이 잘못되어도 초안을 보존하고 직접 작성·저장을 허용한다. AI가
만든 문항에도 4.3 규칙을 적용한다. FormMate는 4.4의 금지 내용을 담은
문항을 제안하지 않도록 지시한다. 호출 비용과 과도한 요청을 막는 기술적
제한은 개발팀이 정한다.

## 4.3 문항 수와 입력 규칙

  -----------------------------------------------------------------------
  **항목**           **허용 범위**
  ------------------ ----------------------------------------------------
  문항 수            3개 이상 30개 이하

  질문 / 보기 문장   질문 5\~200자, 보기 하나당 최대 50자. 공백만 입력한
                     값은 허용하지 않는다. 앞뒤 공백을 뺀 뒤 센다.

  단일선택           보기 2\~10개 중 하나. 기타 입력을 허용하면 입력
                     내용도 저장한다.

  복수선택           보기 2\~10개 중 여러 개. 최소 ≤ 최대 ≤ 보기 수로
                     선택 수를 설정한다.

  척도               1\~5점 중 하나(MVP는 5점만). 1점과 5점의 설명을
                     저장한다.

  단답 / 서술 / 기타 단답과 기타 입력 최대 100자, 서술 최대 500자
  -----------------------------------------------------------------------

필수 여부 기본값은 필수다. 선택 문항은 비워도 되지만 답했다면 유형
규칙을 지켜야 하며, 공백뿐인 답은 미응답으로 본다. 서버는 설문에 없는
문항·보기, 필수 누락, 선택 개수·점수 범위·길이 위반을 확인해 거부한다.

## 4.5 게시 요청 처리 순서

  -----------------------------------------------------------------------
  **순서**           **확인·처리 내용**
  ------------------ ----------------------------------------------------
  1\. 게시 가능 여부 계정이 활성인지, 개인 초안이면 작성자·팀 초안이면
                     현재 팀원인지 확인하고 제목·설명·문항을 4.3 규칙으로
                     검사한다.

  2\. 목표와 날짜    목표 인원(1\~100명)과 마감일은 필수 입력이다. 둘 다
                     목록과 결과에 표시하는 용도다. 마감일은 한국 시간
                     오늘 이후여야 한다. 오늘이 9월 20일이면 9월 19일은
                     불가, 9월 20일은 오늘 23:59까지 받는다. 목표
                     인원이나 마감일을 비우면 게시할 수 없으므로 "마감
                     미설정" 같은 상태는 두지 않는다.

  3\. 게시 확인      게시 후 수정 불가, 마감 30일 후 원문 파기(7.4), 금지
                     내용과 운영 삭제(4.4)를 보여주고 확인을 받는다.

  4\. 게시 완료      상태를 \"임시저장\"에서 \"모집 중\"으로 바꾸고
                     게시자·게시 명의·게시 시각·문항·목표 인원·마감일을
                     확정한다. 목록 맨 위(최신)에 나타난다. 팀 설문이면
                     팀원에게 알린다.
  -----------------------------------------------------------------------

게시 비용과 게시 개수 제한은 없다. 같은 게시 요청이 반복되어도 설문은
하나만 만든다. 두 팀원이 같은 팀 초안을 동시에 게시해도 하나만 게시된다.
실패하면 게시 전으로 되돌리고 초안을 남긴다. 게시 후에는 문항·보기·목표
인원·마감일을 바꿀 수 없으며, 바꾸려면 복사해 새로 게시한다. 모집
중이거나 응답이 있는 설문은 등록자가 삭제할 수 없고 상태로 관리한다.

# 5. 설문 목록과 응답

## 5.1 참여 가능 조건

모집 대상 설정이 없으므로 활성 회원은 누구나 모집 중인 설문에 참여할 수
있다. 예외는 아래와 같다.

  -----------------------------------------------------------------------
  **상황**           **처리**
  ------------------ ----------------------------------------------------
  본인 설문 / 자기   목록에 \"내 설문\"·\"우리 팀\" 표시와 함께 보이되
  팀의 팀 설문       응답 버튼을 막는다(3.3).

  이미 제출한 설문   목록에 \"응답 완료\" 표시와 함께 보이되 다시 제출할
                     수 없다.

  마감 설문          기본 목록에서 빼고 검색 결과에만 보인다. 상세를 열면
                     \"마감된 설문입니다\"를 표시하고 응답을 막는다.

  운영 삭제 설문     어디에도 보이지 않고 응답을 받지 않는다.

  목표를 채운 설문   마감 전이면 계속 참여할 수 있고 점수도 받는다. 목록
                     위치는 바뀌지 않고 \"목표 달성\" 표시만 붙인다.
  -----------------------------------------------------------------------

설문 주소로 직접 접속하거나 제출 요청을 보내도 서버가 같은 조건을 다시
확인한다. 다른 회원의 설문 결과는 볼 수 없다.

## 5.2 전체 설문 목록과 검색

  -----------------------------------------------------------------------
  **항목**           **기준**
  ------------------ ----------------------------------------------------
  기본 목록          모집 중인 설문만 게시 시각 최신순으로 보여준다. 게시
                     시각이 같으면 내부 식별값 내림차순. 내 설문·우리 팀
                     설문·응답 완료 설문도 포함한다. 달성률 기준 정렬과
                     상위 노출 기능은 없다.

  검색               설문 제목의 키워드로 검색한다. 결과는 모집 중 설문을
                     위(게시 최신순), 마감·보관 설문을 아래(마감
                     최신순)에 둔다. 운영 삭제 설문은 나오지 않는다.

  필터               예상 소요 시간(전체 / 3분 이내 / 5분 이내 / 6분
                     이상)으로 거를 수 있다. 필터는 목록 순서를 바꾸지
                     않으며 정렬은 최신순만 둔다.

  표시 정보          제목, 게시 명의(닉네임 또는 팀 이름), 문항 수, 예상
                     소요 시간, 응답 수/목표 인원, 마감일(D-n 또는
                     \"마감\"), 상태 표시(내 설문·우리 팀·응답 완료·목표
                     달성·마감)

  불러오기           한 번에 20개씩 불러오고 스크롤하면 이어서 불러온다.
                     방식은 개발팀이 정한다.
  -----------------------------------------------------------------------

## 5.3 응답 시작과 이어서 응답

  -----------------------------------------------------------------------
  **상황**           **서버 처리**
  ------------------ ----------------------------------------------------
  처음 시작          계정 상태, 참여 가능 조건(5.1), 모집 중·마감 전
                     여부를 확인하고 응답 세션을 만든다.

  답 입력·변경       작성 중인 답을 임시저장한다. 제출 전이므로 응답 수와
                     점수에 반영하지 않는다.

  중단 후 재접속     저장된 답을 불러온다. 그 사이 마감되었으면 계속 받지
                     않는다.

  제출               자격·마감·중복 제출·필수 답변·유형 규칙을 다시
                     확인하고 5.4로 진행한다.

  타인 응답 접근     다른 회원의 작성 중인 답은 조회·수정할 수 없다.
  -----------------------------------------------------------------------

## 5.4 제출과 동일 응답 경고

+-----------------+----------------------------------------------------+
| **단계**        | **처리**                                           |
+=================+====================================================+
| 1\. 동일 응답   | 제출 버튼을 누르면 화면에서 먼저 확인한다. 답한    |
| 확인 (화면)     | 척도 문항이 3개 이상이고 모두 같은 점수이면 경고   |
|                 | 팝업을 띄운다. 단일선택·복수선택·주관식은 보지     |
|                 | 않는다.                                            |
|                 |                                                    |
|                 | 문구 예: \"모든 척도 문항에 같은 점수를            |
|                 | 선택했어요. 성실한 응답이 좋은 설문 결과를         |
|                 | 만듭니다. 이대로 제출할까요?\" \[다시 확인하기\]   |
|                 | \[그대로 제출\]                                    |
+-----------------+----------------------------------------------------+
| 2\. 기본 검사   | 자격·마감·중복·필수 답변·입력 규칙을 확인한다.     |
| (서버)          | 실패하면 이유를 알리고 작성 중인 답은 유지한다.    |
+-----------------+----------------------------------------------------+
| 3\. 제출 저장   | 답변과 제출 시각을 저장하고 설문의 응답 수를 1     |
|                 | 늘린다. 경고를 보고 그대로 제출했는지 여부도 함께  |
|                 | 저장한다(관리자 확인용).                           |
+-----------------+----------------------------------------------------+
| 4\. 점수 반영   | 응답자에게 1점을 주고 이번 주 리더보드에           |
|                 | 반영한다(6장). 저장·응답 수·점수는 한 묶음으로     |
|                 | 처리한다.                                          |
+-----------------+----------------------------------------------------+
| 5\. 완료 화면   | \"응답 완료! +1회\"와 이번 주 내 순위·응답 횟수,   |
|                 | 리더보드 바로가기, 다른 설문 보기 버튼을 보여준다. |
+-----------------+----------------------------------------------------+

경고는 제출 시점에 한 번만 띄우고, 응답 도중에는 띄우지 않는다. \"다시
확인하기\"를 누르면 작성 중인 답을 그대로 둔 채 설문으로 돌아간다.
경고를 보고 그대로 제출한 응답도 정상 집계하고 1점을 준다. 응답 저장
없이 점수만 주지 않는다. 반복 클릭·재요청에는 저장된 결과를 돌려주고
점수를 중복으로 주지 않는다.

## 5.5 오류와 재요청

마감 시각 이후 도착한 제출과 운영 삭제 설문의 시작·제출은 거부한다. 통신
오류 후 재요청이면 이미 접수됐는지 먼저 확인해, 접수됐으면 같은 결과를
돌려주고 아니면 자격과 마감을 확인해 새로 처리한다.

# 6. 주간 응답 리더보드

리더보드는 포인트를 대신하는 응답 동기이자 Uni-Form의 차별점이다. 한 주
동안 다른 회원의 설문에 많이 응답한 회원을 닉네임과 함께 보여주고,
상위권에게 보상을 준다.

## 6.1 응답 점수

  -----------------------------------------------------------------------
  **항목**           **기준**
  ------------------ ----------------------------------------------------
  점수               설문 1건 제출 = 1점. 문항 수와 관계없다.

  점수를 주지 않는   게시 전 확인(시험 응답), 제출 실패, 중복 제출.
  경우               본인·자기 팀 설문은 애초에 응답할 수 없다.

  점수 차감          자동 차감은 없다. 운영자가 부정 응답을 확인하면
                     관리자 화면에서 해당 점수를 빼고 사유를
                     기록한다(10.4).
  -----------------------------------------------------------------------

## 6.2 시즌(주간)

한 시즌은 한국 시간 월요일 00:00부터 일요일 23:59까지다. 제출 요청의
서버 도착 시각이 속한 주에 점수를 넣는다. 월요일 00:00에 순위를
초기화한다. 지난 시즌 내 최종 순위는 리더보드의 내 순위 영역에서 볼 수
있고, 회원별 누적 응답 수는 마이페이지에 따로 표시한다.

## 6.3 보상

  -----------------------------------------------------------------------
  **항목**           **기준**
  ------------------ ----------------------------------------------------
  보상 내용          미정. 구체적인 상품은 운영팀이 확정한 뒤 이 명세서와
                     리더보드 공지에 넣는다. 운영팀 자체 예산으로
                     지급한다. 화면·관리자 기록에는 상품명을 고정값으로
                     넣지 않고 관리자가 입력한 보상 문구를
                     보여준다(10.4).

  보상 인원          매주 상위 3위(1위 1명, 2위 1명, 3위 1명). 예산에
                     따라 운영팀이 조정하고, 바뀌면 시즌 시작 전에
                     리더보드 상단에 공지한다.

  확인               시즌 종료 후 운영자가 관리자 화면에서 보상 대상의
                     이번 주 응답을 확인한다. 부정 응답이 확인되면 점수를
                     빼고 다음 순위자에게 넘긴다.

  발송               가입 이메일로 보상을 보낸다. 발송 여부·일시·보상
                     내용을 관리자 화면에 기록한다. 대상자에게는
                     앱·이메일로 먼저 알린다(8.4).

  제외               이용 제한·탈퇴 회원, 운영팀 구성원 계정
  -----------------------------------------------------------------------

## 6.4 화면 구성

  -----------------------------------------------------------------------
  **영역**           **표시 내용**
  ------------------ ----------------------------------------------------
  상단 안내          이번 주 기간(월\~일)과 남은 시간, 이번 주 참여
                     인원("N명 참여 중")을 보여준다.

  1\~3위 시상대      가운데 1위(금색), 왼쪽 2위(은색), 오른쪽 3위(동색)
                     단상으로 보여준다. 닉네임 첫 글자 아바타, 닉네임,
                     응답 횟수를 표시한다.

  순위 목록          1위부터 순위·닉네임·응답 횟수·최근 활동일(마지막
                     제출 날짜)을 표로 보여준다. 한 페이지에 10명씩,
                     페이지 번호로 이동하며 50위(5페이지)까지 표시한다.
                     응답 0회 회원은 넣지 않는다.

  보상 안내          1\~3위 보상을 순위별로 보여준다. 상품은 미정이므로
                     관리자가 입력한 보상 문구를 표시한다(6.3, 10.4).

  운영 기준          실제 제출한 응답만 집계한다는 것, 운영자가 부정
                     응답으로 확인하면 횟수에서 빠질 수 있다는 것(10.4),
                     동점 표시와 보상 동점 추첨 규칙(6.5), 기준이 바뀌면
                     시즌 시작 전에 공지한다는 것을 안내한다.

  내 순위            이번 주 내 순위와 응답 횟수("이번 주 총 N회
                     참여했어요"), 바로 위 순위와의 차이("바로 위와 N회
                     차이", 차이가 0이면 "공동 순위", 1위면 "전체 1위"),
                     지난주 내 최종 순위를 보여준다. 51위 이하도 여기서
                     확인한다. 0회면 "이번 주 첫 응답을 해보세요"를
                     보여준다.

  랜딩 미리보기      랜딩 페이지의 리더보드 소개 영역에 이번 주 1\~3위
                     시상대와 1\~10위 목록 미리보기, "이번 주 순위
                     확인하기" 버튼을 둔다. 보상 문구는 보상 안내와 같은
                     관리자 입력 문구를 쓴다.

  갱신               제출 후 다음 조회부터 반영한다. 실시간 자동 갱신은
                     필수가 아니다.
  -----------------------------------------------------------------------

## 6.5 동점 처리

응답 횟수가 같으면 같은 순위로 표시하고(예: 1, 2, 2, 4위) 내 순위 영역에
"공동 순위" 배지를 붙인다. 같은 순위 안에서는 최근 활동일(마지막 제출
시각)이 빠른 회원, 즉 그 횟수에 먼저 도달한 회원을 위에 둔다. 보상
순위에서 동점자가 보상 인원보다 많으면 **무작위 추첨**으로 보상 대상을
정한다. 이 규칙은 리더보드의 운영 기준 영역과 이용약관에 항상 공지한다.
추첨은 운영자가 관리자 화면의 추첨 기능으로 하고, 추첨 대상·결과·시각을
기록한다.

## 6.6 표시 제외와 부정 방지

이용 제한·탈퇴 회원은 리더보드에서 뺀다. 불성실 응답 자동 판정이
없으므로 점수만 노린 대충 응답을 막는 장치는 동일 응답 경고(5.4),
관리자의 점수 차감(10.4), 보상 전 응답 확인(6.3)이다. 관리자 화면에서
경고 후 그대로 제출한 응답이 많은 회원을 먼저 볼 수 있게 한다.

# 7. 설문 결과

## 7.1 기본 원칙

  -----------------------------------------------------------------------

  ------------------ ----------------------------------------------------
  조회 권한          본인 설문은 등록자만, 팀 설문은 현재 팀원 전원이
                     본다(3.3). 공유 링크는 이후 단계에서 추가한다.

  실시간 공개        모집 중에도 볼 수 있고 새 응답은 다음 조회부터

## 7.2 화면 구성과 문항별 그래프

결과 화면은 "문항별 결과"(기본)와 "요약" 두 탭으로 나눈다. 요약 탭에는
응답 수/목표 인원, 달성률, 마감일과 남은 기간, 하루 단위 응답 추이, 파기
예정일(마감 후)을 보여준다. 응답이 0건이면 탭 없이 안내 문구만 보여준다.
문항별 결과 탭은 문항 순서대로 결과를 보여준다.

  -----------------------------------------------------------------------
  **유형**           **보여주는 방법**
  ------------------ ----------------------------------------------------
  단일선택           원그래프. 보기별 응답 수와 비율을 함께 표시한다.
                     기타 입력은 그래프 아래 목록

  복수선택           가로 막대 그래프. 보기별 선택 수와 \"이 문항 응답자
                     중 선택한 비율\". 합이 100%를 넘을 수 있다고
                     안내한다.

  척도               1\~5점 세로 막대 그래프와 평균. 양 끝 설명을 축에
                     표시한다.

  단답·서술          응답 목록과 건수. 제출 순서가 드러나지 않게 무작위
                     고정 순서로 보여준다. 그래프는 없다.
  -----------------------------------------------------------------------

비율의 분모는 그 문항에 답한 응답 수이며 선택 문항은 미응답 건수를 따로
표시한다. 소수점 한 자리로 표시하되 계산에는 반올림 전 값을 쓴다.

# 8. 마이페이지와 대시보드

## 8.1 프로필

상단에 닉네임, 이번 주 순위·점수, 누적 응답 수를 보여준다. 닉네임·프로필
확인과 변경(2.3), 가입 이메일 확인, 비밀번호 변경(2.4), 마케팅 수신
설정(변경 시각 기록), 동의한 약관 확인, 내가 속한 팀 목록과 팀
만들기·초대 링크 가입(3장), 고객센터(9장), 탈퇴(2.5)를 제공한다.

## 8.2 내 응답 내역

제출한 설문의 제목, 제출일, 받은 점수를 보여준다. 도중에 멈춘 설문은
\"작성 중\"으로 따로 보여주고 마감 전이면 이어서 답하게 한다. 제출한
답은 파기 전까지 볼 수 있고 수정할 수 없다. 받은 보상 내역(주차, 순위,
발송일)도 여기서 보여준다.

## 8.3 내 설문 관리와 직접 마감

본인 설문과 소속 팀의 팀 초안·팀 설문을 상태별 탭으로 보여준다. 각
설문에 제목, 게시 명의(본인/팀 이름), 문항 수, 응답 수/목표, 달성률,
마감일, 파기 예정일을 표시한다.

  -----------------------------------------------------------------------
  **상태**           **할 수 있는 동작**
  ------------------ ----------------------------------------------------
  임시저장           이어서 작성, 게시 전 확인, 게시, 복사, 삭제(팀
                     초안은 3.1 권한)

  모집 중            결과 보기, 그래프 내려받기, 직접 마감(본인 설문은
                     등록자, 팀 설문은 팀장), 복사

  마감 / 보관        결과 보기, 그래프 내려받기, 복사, 보관 또는 보관
                     해제

  운영 삭제          삭제 사유와 고객센터 안내 보기, 삭제 전까지의 결과
                     보기
  -----------------------------------------------------------------------

**직접 마감**은 모집 중인 설문만 가능하다. 다시 열 수 없고, 30일 후
원문이 파기되며, 다시 모집하려면 복사해 새로 게시해야 한다는 점을
확인받는다. 마감 요청의 서버 도착 시각을 마감 시각으로 하고 상태 변경과
함께 한 묶음으로 처리한다. 이후 도착한 제출은 \"설문이
마감되었습니다\"로 거부하고 점수를 주지 않는다.

## 8.5 대시보드

로그인한 회원이 자기 활동을 한눈에 보는 화면이다. 상단 메뉴에서
들어가며, 요약 카드와 최근 활동은 본인(과 소속 팀) 기준이다. 다른 회원에
대해서는 리더보드(6장)에 이미 공개된 닉네임·점수 외에는 보여주지 않는다.
대시보드용 조회 API를 따로 둔다.

  -----------------------------------------------------------------------
  **영역**           **표시 내용**
  ------------------ ----------------------------------------------------
  상단 영역          기간 선택(최근 7일 / 최근 30일 / 최근 3개월, 기본
                     7일)과 바로가기 버튼(FormMate로 설문 만들기, 내 설문
                     보기)을 둔다. 고른 기간은 주소에 남겨 새로고침해도
                     유지한다.

  요약 카드          카드 4개를 보여주고, 누르면 관련 화면으로 이동한다.
                     ① 진행 중인 설문: 모집 중인 내 설문 수(내 설문의
                     모집 중 목록으로 이동) ② 누적 응답 수: 내 설문에
                     모인 전체 응답 수 ③ 분석 가능한 설문: 응답이 1건
                     이상인 내 설문 수 ④ 이번 주 참여 횟수: 이번 주 내가
                     제출한 응답 수(= 리더보드 응답 횟수)와 지난주 대비
                     증감(설문 목록으로 이동)

  참여 추이 차트     선택한 기간의 흐름을 막대 7개로 보여준다. 최근 7일은
                     하루 단위, 30일·3개월은 기간을 7구간으로 나눠
                     묶는다. 기준 토글로 응답 수(건)와 설문 수(개)를 바꿔
                     볼 수 있고, 막대에 마우스를 올리면 날짜와 값을
                     보여준다. 응답 수·설문 수를 내 활동 기준으로 셀지
                     서비스 전체 기준으로 셀지는 팀에서 확정한다(12.3 ⑨).

  최근 활동          내 최근 활동을 최신순으로 4건 보여준다. 항목마다
                     제목, 한 줄 설명, 상대 시간(예: 2시간 전)을 표시하고
                     누르면 해당 화면으로 이동한다. 대상: 설문 참여(응답
                     제출), 내 설문 게시, 내 설문 결과 확인 등.
                     "전체보기"는 내 설문 화면으로 연결한다.

  응답자 보호        차트와 최근 활동에는 누가 내 설문에
                     응답했는지(응답자 닉네임·개별 제출 시각)를 보여주지
                     않는다(7.1).

  빈 상태 / 오류 /   활동이 없으면 카드는 0으로, 최근 활동은 첫 설문 참여
  갱신               안내로 보여준다. 불러오기에 실패하면 오류 문구와
                     "다시 시도" 버튼을 보여준다. 조회 시점 기준이며

# 10. 관리자 화면

## 10.1 접근과 기록

관리자 계정은 일반 가입으로 만들 수 없고 개발팀이 권한을 준다. 관리자
화면은 일반 서비스와 다른 주소로 들어가며 관리자 권한이 없으면 모든
요청을 거부한다. 모든 조치는 조치자·시각·대상·사유와 함께 기록하고
지우지 않는다. 첫 화면에는 오늘·이번 주 가입자 수, 게시 설문 수, 응답
수를 보여준다.

## 10.2 설문 관리

  -----------------------------------------------------------------------

  ------------------ ----------------------------------------------------

                     이름·게시일로 찾는다. 설문
                     내용(제목·설명·문항·보기)을 열어볼 수 있다.

# 12. 결정 사항과 남은 과제

## 12.1 확정 사항

  -----------------------------------------------------------------------
  **구분**           **내용**
  ------------------ ----------------------------------------------------
  제외               포인트 제도, 불성실 응답 확인 기능, 로그 데이터
                     수집, 게시 전 금지 내용 필터링, 모집 대상 설정, 목록
                     상위 노출, 결과 보고서, 교차 분석·통계 검정, 응답
                     데이터 내려받기

  회원               가입 시 닉네임과 프로필(성별·학년·전공 계열·재학
                     상태) 필수 입력, 닉네임 중복 불가, 닉네임·프로필
                     변경 제한 없음

  팀                 팀원 전원이 팀 초안 공동 작성, 팀 설문 현황·결과
                     요약 조회. 팀원은 자기 팀 설문 응답 불가. 팀
                     리더보드 없음

  목록               모집 중 설문 최신순. 내 설문·응답 완료 설문은 표시만
                     하고 응답 막음. 마감 설문은 기본 목록에서 숨기고
                     검색 시 아래쪽에 표시. 목표 인원·마감일은 필수
                     입력이며 표시용

  응답               척도 3개 이상이 모두 같으면 경고 팝업, 무시하고
                     제출해도 점수 지급

  리더보드           설문 1건 1점, 주간 집계, 1\~3위 금·은·동, 동점 시
                     무작위 추첨 사전 공지, 보상 상품은 추후 확정(운영팀
                     사비)

  결과               구글폼식 실시간 그래프(원그래프·막대), 그래프
                     이미지만 내려받기

  운영               마이페이지에 프로필·응답 내역·내 설문 관리 포함,
                     대시보드(요약 카드·주간 참여 추이·최근 활동 피드)
                     MVP 포함, 고객센터 이메일, 관리자 화면에서 규정 위반
                     설문 직접 삭제
  -----------------------------------------------------------------------
